# 🍽️ Odin Recipes

## Descripción

Odin Recipes es mi primer proyecto web en HTML y CSS. El objetivo de este recetario fue practicar la estructura básica de una página web, organizar contenido de forma clara y poner en práctica mis conocimientos iniciales de desarrollo web.

En este proyecto comparto algunas de mis recetas saludables favoritas, utilizando imágenes tomadas por mí para complementar la presentación del sitio.

## ✨ Características

- Página tipo recetario con estructura simple.
- Uso de HTML para la organización del contenido.
- Aplicación de estilos básicos con CSS.
- Inclusión de imágenes propias.
- Enfoque en legibilidad y presentación clara de las recetas.
